# Air Juggler

A web-based interactive game where players use hand gestures detected via webcam to keep virtual balls in the air.

## Project Overview

Air Juggler is a gesture-controlled game that provides an interactive canvas-based gaming experience with a responsive user interface and  animations.

## Current Status

### Completed

- Frontend UI (fully styled and responsive)
- HTML structure and layout
- CSS styling with animations
- UI components (start button, score display, game overlay)
- Hand gesture detection
- Multiple difficulty levels
- Score tracking
- Responsive design
- Sound effects and visual feedback
- Game completion conditions

## Getting Started

### Prerequisites

- Modern web browser with webcam support
- (Optional) Node.js for local development server

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yugrajjoshi/Ball-juggler.git
cd Ball-juggler
```

1. Open index.html in your web browser or run a local server:

```bash
python -m http.server
```

### Webcam Permissions

The game requires camera access. You will be prompted to allow webcam permissions when starting the game.
